## 👨🏻‍💻 نبذة عني (About Me)

- 💻 **مطور ويب متكامل (Full Stack Web Developer)** شغوف ببناء تطبيقات وتجارب ويب ذكية ومبتكرة.
- 🧠 **الذكاء الاصطناعي:** مهتم جداً بدمج نماذج الذكاء الاصطناعي والـ APIs (مثل Gemini API) في المشاريع البرمجية.
- 🚀 **التطوير المستمر:** أعمل دائماً على تجارب برمجية جديدة وأحب أتمتة العمليات المعقدة وسكربتات البيانات.
- ⚡ **حكمة برمجية:** "استكشف المعرفة وتعمق بها، لتصنع حلولاً تترك أثراً حقيقياً".
